# GAS 雲端後端｜部署說明

> 對象：要接手部署「打卡雲端」的人
> 前提：Google 帳號、可上網、電腦已裝 Node.js（`npx` 可用）

---

## 一、這包裡有什麼

資料夾 **`gas-deploy/`**：

| 檔案 | 用途 | 要不要推上雲端 |
|---|---|---|
| `punch_appscript.gs` | **後端主程式**（GAS 伺服器邏輯） | ✅ 是 |
| `PunchPage.html` | **手機打卡頁**（前端） | ✅ 是 |
| `appsscript.json` | GAS 專案設定（時區／V8／API 存取） | ✅ 是 |
| `deploy.bat` / `deploy.sh` | 一鍵部署腳本（先 push 再 redeploy） | ❌ 本機用 |
| `.claspignore` | 推送白名單（只推上面 3 檔） | ❌ 本機用 |
| `.clasp.json.tmpl` | **設定檔範本**（要自己填 scriptId） | ❌ 本機用 |

> ❗本包**不含任何真實憑證**：沒有 scriptId、沒有 deploymentId、沒有登入 token。
> 這些都要**收件人用自己的 Google 帳號產生**（見下方步驟）。

---

## 二、首次部署（完整步驟）

### 步驟 0：前置

```bash
# 需要 Node.js；確認可用
node -v
npx -v
```

### 步驟 1：建立 GAS 專案

1. 開 <https://script.google.com> → **新增專案**。
2. 專案改名（例如「HR 打卡系統」）。
3. 從網址列複製 **scriptId**（`/projects/` 之後那一長串）：
   ```
   https://script.google.com/home/projects/【這串就是 scriptId】/edit
   ```

### 步驟 2：設定本機部署資料夾

1. 在 `gas-deploy/` 資料夾內，把 **`.clasp.json.tmpl` 改名為 `.clasp.json`**。
2. 打開它，把 `scriptId` 換成步驟 1 拿到的那串：
   ```json
   {
     "scriptId": "你剛剛複製的那串",
     "rootDir": "."
   }
   ```

### 步驟 3：登入 Google（只需做一次）

```bash
npx @google/clasp login
```

會開瀏覽器請你授權。**token 只存在你本機**（`~/.clasprc.json`），不會經過任何人。

### 步驟 4：部署

**Windows：**
```bash
cd gas-deploy
deploy.bat
```

**macOS / Linux / Git Bash：**
```bash
cd gas-deploy
bash deploy.sh
```

> 這一步會 `push --force` 把 3 個檔推上雲端（更新專案 HEAD）。

### 步驟 5：第一次建立 Web App（產生手機網址）

1. 回到 <https://script.google.com> 開你的專案。
2. 右上 **部署 → 新增部署作業**。
3. 類型選 **網頁應用程式**。
4. 設定：
   - **執行身分**：我（自己的帳號）
   - **具有存取權的人**：**任何人**
5. 按 **部署** → 複製產生的 **`/exec` 網址**（這就是手機打卡頁網址）。

---

## 三、之後更新（改版重推）

之後只要改了 `punch_appscript.gs` 或 `PunchPage.html`：

```bash
cd gas-deploy
deploy.bat <你的deploymentId>
```

> ### ⚠️ 兩個腳本的關鍵差異（很容易搞錯）
> - `deploy.bat` / `deploy.sh` **有給 deploymentId** → 會 `redeploy`，**原 `/exec` 網址不變**（手機舊連結照用）。
> - **沒給** deploymentId → 只 `push`，不動任何既有部署。
> - ❗**絕對不要用 `clasp deploy`**（會建「新」部署 → 產生**新網址**，手機舊網址不會更新）。
>
> **deploymentId 哪裡找？** script.google.com → 你的專案 → **部署 → 管理部署作業** → 點該部署，複製「部署 ID」。

---

## 四、把手機頁接上後端（重要）

`HR系統.html` 與 `PunchPage.html` 需要知道雲端網址才會同步。設定位置：

- **HR 系統主檔** → 「設定」頁 → **雲端同步** → 貼上你的 **`/exec` 網址** → 儲存。
- 之後：
  - 主檔按「**從雲端同步打卡**」拉資料
  - 員工用手機開 `/exec` 網址打卡

> 換了新 GAS 專案 = 新網址 → **記得回主檔設定頁更新網址**，否則兩邊不同步。

---

## 五、雲端試算表

`punch_appscript.gs` 會在**它綁定的 Google 試算表**上建立需要的分頁
（打卡、請假、加班、補休、排班、員工名單…）。

- 首次執行時，GAS 會請你授權（同意即可）。
- 若想指定試算表：在 GAS 專案裡用 **「資源 → 進階 Google 服務」** 或直接在 `punch_appscript.gs`
  設定 `SPREADSHEET_ID`（依你的版本而定；本版沿用綁定的試算表）。

## 六、疑難排解

| 症狀 | 處理 |
|---|---|
| `clasp login` 失敗 | 確認網路、Node 版本；重試 `npx @google/clasp login --no-localhost` |
| push 後雲端沒變 | 確認 `.clasp.json` 的 scriptId 正確、且 `.claspignore` 沒有把檔案排除 |
| 手機頁打不開 | 檢查部署的「具有存取權的人」是否設為**任何人** |
| 改了程式但手機仍舊版 | 你是不是只 `push` 沒 `redeploy`？要帶 deploymentId 重跑 |
| 主檔讀不到打卡 | 設定頁的 `/exec` 網址是不是舊的？換專案要更新 |
| 出現「未授權」 | 在 GAS 編輯器手動執行一次任一函式，完成 OAuth 同意 |

## 七、安全提醒

- **`.clasp.json`、`~/.clasprc.json` 都是私密檔**，不要上傳、不要外流、不要進版控。
- 本包已刻意**移除**這些憑證與真實 deploymentId；若你自行填入後要再分享，請記得先清掉。
- GAS 專案權限建議：**只有你能編輯**，Web App 才設「任何人」存取（僅執行）。

### 7-1 建議開啟「寫入權杖」（選用，預設關閉）

**問題**：Web App 必須設成「任何人」存取，手機才能打卡。代價是——

> **只要知道你的 `/exec` 網址，任何人都能直接呼叫寫入端點**
> （上傳排班、核准請假、匯入員工名單、切換月結鎖定…）。

**解法**：設一組權杖，寫入端點必須帶著它才放行。

| 步驟 | 動作 |
|---|---|
| 1 | Apps Script 編輯器 → 左側 **⚙ 專案設定** → 拉到最底 **指令碼屬性** |
| 2 | 新增屬性：名稱 `WRITE_TOKEN`，值填一組**你自己定的長亂數**（例如 32 字元以上） |
| 3 | 儲存 → **重新部署**（`deploy.sh`／`deploy.bat` 或手動「管理部署 → 新版本」） |
| 4 | 主系統 → **設定 → 雲端中繼設定 → 雲端寫入權杖** 填同一組值 → 「儲存設定」 |
| 5 | 按 **「測試雲端連線」**，訊息應顯示「寫入權杖：**已啟用且正確** ✅」 |

**行為說明（很重要）**

- **沒設 `WRITE_TOKEN` → 不啟用**，行為與舊版完全相同。所以你可以先不設，不會弄壞任何東西。
- 權杖**只擋寫入**。讀取（`health`／`emps`／`punches`／`getschedule`…）不受影響。
- **手機打卡頁不受權杖影響**：手機端是 `google.script.run` 直接呼叫函式，不經過 `doGet`／`doPost`。
  員工那條防線是 **PIN 驗證**；把共用權杖寫進手機頁 HTML 等於公開，所以刻意不這樣做。
- ❗寫入用的是 `no-cors` POST，**讀不到回應**。權杖填錯時畫面不會報錯，只會「按了沒反應」。
  所以**每次改權杖後，務必先按「測試雲端連線」確認狀態**。
- 權杖走網址 query，會留在瀏覽器歷史與伺服器日誌，屬「擋掉不知情的掃描者」，
  不是「抗攔截的加密憑證」。**請把 `/exec` 網址本身也當機密。**

### 7-2 已內建的其他防線

| 項目 | 狀態 |
|---|---|
| 員工 PIN 不外洩 | `op=emps` 只回 `hasPin` 布林；驗證走伺服器端 `op=verify` |
| JSONP callback 白名單 | `callback` 只接受合法 JS 識別字，不符回純 JSON（防反射型 XSS） |
| 加班申請期限 | `OT_WINDOW_DAYS = 7`（GAS 與手機頁必須同值） |
| 月結鎖定 | 資料所屬月「次月 5 日」起不得再寫入（`MONTH_CLOSE_ENABLED`，預設關閉） |
