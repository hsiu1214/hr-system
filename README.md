# HR 系統（單檔 HTML ＋ Google Apps Script 雲端打卡）

一套為台灣小型餐飲業（< 20 人）設計的**離線優先** HR／薪資系統。
採 **單檔 HTML ＋ SheetJS 內嵌**，零相依、離線可用；需要手機打卡時，可選配
**Google Apps Script（GAS）** 雲端後端，員工用手機開網頁打卡，主檔再從雲端同步。

> 雇主／採購方視角設計。薪資、出勤、加班（含補休折現）、請假、年終獎金試算全部在瀏覽器本機計算，
> 人事資料不外傳。

## 功能一覽

| 模組 | 內容 |
|---|---|
| 員工名冊 | 23 欄（含身分證、銀行帳號、投保級距、PIN）；在職／離職篩選、調薪版本列 |
| 薪資試算 | 正職（月薪）／計時（時薪）兩套邏輯、遲到早退、國定假日雙倍、薪資條法定揭露 |
| 出勤統計 | 打卡、補登、更正、預警（14 種 code）、休息時數取整、薪資條出勤比對 |
| 加班申請制 | 正職一律申請制；國定假日加班費；補休 ledger（1:1）與折現；計時人員即時打卡免申請 |
| 請假管理 | 13 種假別、有薪判定、額度控管、雲端申請／核准 |
| 排班 | `排班-YYYY-MM` 分頁、35 欄、逐人時段、月曆檢視、計時／正職差異化 |
| 年終獎金 | 獨立 16 欄分頁、逐人倍數、PIN 鎖定、匯出 |
| 薪資所得申報 | 年度薪資清冊／薪資印領清冊／免稅額申報表（三張表，含可展開明細） |
| 法規規範頁 | 13 個面板（勞動規範參數、國定假日曆、勞健保級距） |
| 雲端打卡（選配） | 手機網頁打卡 → 寫入 GAS 綁定的 Google 試算表 → 主檔同步 |

### 法規版本

- **勞健保級距支援年度化**：`BUILTIN_LABOR_TIER_BY_YEAR` 依薪資年度自動選表。
- 已內建 **2026 年（115 年）** 與 **2027 年** 級距。
- 2027 年基本工資 30,900 元／時薪 205 元、勞保費率 13%（含就保 1%）。
  ⚠️ 2027 年「投保薪資分級表」若勞保局另行公告調整，需覆核級距。

## 快速開始（本機測試）

1. 把 `HR主檔_範本.xlsx` **另存一份**為 `HR主檔.xlsx`（或任何你喜歡的名字），放在本機。
2. 雙擊 `啟動HR系統.bat`（推薦，功能最完整），或直接開 `HR系統.html`。
3. 點右上「選擇主檔」載入你剛才那份 Excel。
4. 首次開啟會出現 **admin 密碼閘門**，預設 `0000` —— **正式使用前務必更改**。
5. 想先看計算結果：依 `測試數據_2026Q1/說明.md` 把假資料貼入，到「薪資試算」頁比對 `expect.json`。

> **為什麼要用 .bat？** 瀏覽器只允許「安全來源」（localhost）使用 File System Access API
> 直接覆寫主檔；直接開 `file://` 會改為「另存新檔」模式。若資安政策擋 PowerShell，
> 直接開 HTML 一樣可用，只是存檔要多按一步。

## 雲端打卡部署（選配）

詳見 [`gas-deploy/部署說明.md`](gas-deploy/部署說明.md)。摘要：

1. 在 <https://script.google.com> 建一個新專案，複製 **scriptId**。
2. 把 `gas-deploy/.clasp.json.tmpl` 改名為 `.clasp.json`，填入 scriptId。
3. `npx @google/clasp login` → `cd gas-deploy && bash deploy.sh`（Windows 用 `deploy.bat`）。
4. GAS 編輯器「部署 → 新增部署作業」→ 選「網頁應用程式」→ 取得 `/exec` 網址。
5. 回主系統「⚙ 設定 → 雲端同步」貼上 `/exec` 網址，按「測試連線」→「上傳員工名單」。

> ⚠️ 更新**既有**部署請帶 deploymentId 用 `redeploy`，**不要用 `clasp deploy`**（會產生新網址，手機舊連結會失效）。

## 安全性設計

### 憑證與個資

- **本倉庫不含任何真實憑證**：沒有 scriptId、deploymentId、clasp token。
- `HR主檔.xlsx`、`*.gsheet`、`.clasp.json` 已透過 `.gitignore` 排除。
  - `HR主檔.xlsx` 含員工個資，請在本機維護，**勿提交**。
  - `HR主檔_範本.xlsx` 是空白結構，可安全公開。
- `測試數據_2026Q1/` 內的所有姓名、身分證、手機、Email 均為**虛構假資料**
  （如 `A123456789`、`0912-xxx-xxx`、`example.com`）。

### 手機打卡的 PIN 驗證

- 雲端**不再回傳員工 PIN**。`op=emps` 只回 `hasPin` 布林值。
- 員工編號＋PIN 的比對改由**伺服器端** `op=verify`（`verifyEmpPin()`）執行，
  成功才回傳 `{員工編號, 姓名}`，不含 PIN。
- 手機端不持有全店 PIN 清單，即使名單外流也拿不到登入憑證。

> ⚠️ **已知限制**：GAS Web App 採用「任何人（匿名）」部署，端點本身沒有帳號驗證機制。
> PIN 為 4 位數時，若 `/exec` 網址外流，仍可能被逐一嘗試。
> **請把 `/exec` 網址視為機密**，並在正式環境使用較長的 PIN。

### admin 權限

- admin 密碼存於主檔「設定」分頁（本機檔案，不上雲端），用於補登／更正／年終解鎖／月結鎖切換。
- 員工 PIN 在名冊中以 `****` 遮罩顯示；編輯時留白＝維持原密碼。
